# 기상술사 ArkGrid 코어 효과 참조

계산 보고서에는 원본 API 본문을 발췌하지 않는다. 원본은
`outputs/*_api_raw.json`의 `responses.arkGrid`와 엔드포인트별 `rawBody`,
정규화 결과는 `outputs/*_parsed.json`의 `arkGrid.cores`에서 확인한다.

## 판정 규칙

- `ArkGrid.Slots[].Point`가 `[nP]` 이상일 때 해당 옵션이 활성화된다.
- `Slot.Tooltip`이 등급별 확정 수치를 제공하면 그 값을 사용한다.
  참조문처럼 `A/B%`가 남은 경우에는 유물 코어가 A, 고대 코어가 B를
  선택한다.
- `[18P]`, `[19P]`, `[20P]`는 각각 별도 효과이므로 현재 포인트까지
  누적한다.
- 공격력·무기 공격력·치명타율·치명타 피해·공격/이동 속도 등 단순
  스탯의 평면·퍼센트 증가는 카테고리 안에서 합연산한다.
- `추가로 증가`라고 적힌 효과는 같은 코어의 직전 동일 카테고리·범위
  인자에 합산한다. 그 외 피해·대상 방어력 감소 효과는 활성 임계치마다
  별도 인자로 곱한다.
- 예: 고대 현란한 공격 20P의 일반 피해는
  `(1 + 0.005 + 0.015) × 1.0016³`이다. 치명타 시 피해는
  `(1 + 0.0055 + 0.0110)`이다.
- 조건부 효과는 `max-favorable-example-boss-v1`에서 조건 충족으로
  평가하되, 스킬 이름·스킬 태그 범위가 일치해야 적용한다.
- 재사용 대기시간 효과는 구조화해 보존하지만 1회 피해에는 적용하지 않는다.
- 생존·회복·보호막·무력화·파티 지원 효과와 계수 없는 추가 타격/화상은
  1회 개인 피해에서 제외 사유를 기록한다.

## 계산 카테고리

| 정규화 키 | 계산 위치 |
|---|---|
| `attackPowerFlat`, `attackPowerPercent` | 재구성 공격력 |
| `weaponAttackFlat`, `weaponAttackPercent` | 재구성 무기 공격력 |
| `additionalDamagePercent` | 추가 피해 합산 그룹 |
| `generalDamagePercent`, `bossDamagePercent` | `추가로 증가`는 직전 동일 인자에 합산, 나머지는 임계치별 곱연산 |
| `skillDamagePercent` | 스킬 이름·태그 일치 후 `추가로 증가`는 합산, 나머지는 임계치별 곱연산 |
| `criticalRate`, `criticalDamage` | 치명타율·기본 치명타 피해 |
| `criticalHitDamagePercent` | 치명타 적중 시 임계치별 최종 피해 배율 |
| `attackSpeed`, `moveSpeed` | 속도 및 음속 돌파·돌격대장 입력 |
| `enemyDefenseReductionPercent` | 임계치별 잔여 방어력 배율 |
| `cooldownReductionPercent/Seconds` | 로테이션/DPS용 구조화 값, 1회 피해 제외 |
