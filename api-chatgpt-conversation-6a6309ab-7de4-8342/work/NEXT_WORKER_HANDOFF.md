## 완료한 핵심 작업

- `ArkGrid.Effects[]`의 공격력·추가 피해·보스 피해를 계산 카테고리에 연결했다.
- 활성 젬 개별 합계와 `ArkGrid.Effects[]`는 같은 효과 레벨의 중복 표현으로
  판단했다. `Effects[]`를 권위값으로 사용하며 개별 젬 값은 검산/대체용이다.
- 카르마 깨달음은 레벨당 무기 공격력 `0.1%`로 적용한다.
- 프로필 공격력과 재구성 공격력이 다르면 재구성 과정은 보고하되 실제 스킬
  피해에는 프로필 공격력을 사용한다.
- 아크그리드 질서/혼돈 코어의 포인트, 유물/고대 분기와 합연산·곱연산 규칙을
  구현했다. 18~20P는 활성 포인트마다 독립 적용한다.
- `공간 가르기`를 우산 스킬로 수정했고 봄날꽃씨·시아나즈 보고서를 갱신했다.
- 봄날꽃씨의 `바람송곳`, `칼바람`, `몰아치기`, `회오리 걸음` 모션식을
  추가하고 개별 계산 보고서를 생성했다.
- 일반 피해 보석은 해당 스킬 계산에 한 번만 적용하며 재사용 대기시간 보석은
  1회 피해가 아닌 향후 로테이션/DPS용 데이터로 보존한다.
- 계산 보고서에서 `핵심 원본 데이터 발췌`와 `아크그리드 전체 효과 적용 전후`
  섹션은 출력하지 않는다. 원본/파싱 자료는 `outputs`의 JSON에서 확인한다.

## 꼭 확인할 계산 가정

- 신규 네 스킬의 사용자 제공 모션계수·모션상수는 봄날꽃씨의 현재 선택
  트라이포드 조합이 반영된 값으로 취급했다.
- 따라서 `역류` 피해 배율은 모션식에 내장된 것으로 보고 별도로 다시 곱하지
  않았다. 계수가 트라이포드 적용 전 값이었다면 이 부분을 수정해야 한다.
- `칼바람-벼락` 치명타 피해 `+210%`, `몰아치기-우레` 치명타 피해 `+180%`는
  공용 치명타 피해에 별도로 합산한다.
- 네 스킬의 방향 타입은 API에 명시 필드가 없어 `NON_DIRECTIONAL`로 잠정
  분류했다.
- 보고서는 `max-favorable-example-boss-v1` 시나리오다. 운명: 비연참 및
  기류 보호막 조건이 충족된 최대 유리 조건을 사용한다.
