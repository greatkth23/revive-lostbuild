## v2.4.2 수정

- 깨달음 카르마 무기 공격력을 `카르마 레벨 × 0.1%`로 계산한다.
  - 봄날꽃씨: 27레벨 → 2.7%
  - 시아나즈: 30레벨 → 3.0%
- 활성 젬의 개별 효과와 `ArkGrid.Effects[]` 통합 효과는 같은 효과
  레벨에서 나온 값이므로 중복 합산하지 않는다.
- `ArkGrid.Effects[]`를 최종 권위값으로 사용하고 개별 젬 값은
  검산·출처와 통합 필드 누락 시 대체값으로만 보존한다.
- 시아나즈 공격력 ArkGrid 적용값:
  - 활성 젬 단순 표시값 2.49%: 검산용, 미합산
  - `Effects[]` 공격력 70레벨 2.56%: 실제 적용
  - 혼돈의 별 코어 공격 19P 2.52%: 실제 적용
  - 최종 ArkGrid 공격력 증가: 2.56% + 2.52% = 5.08%
