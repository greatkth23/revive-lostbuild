- `arkGrid.Effects[2]` 추가 피해: 이번 범위에서는 포인트 활성 효과 제외
- `arkGrid.Effects[3]` 보스 피해: 이번 범위에서는 포인트 활성 효과 제외
- `arkGrid.Effects[4]` 아군 공격 강화: 이번 범위에서는 포인트 활성 효과 제외
- `arkGrid.Effects[5]` 아군 피해 강화: 이번 범위에서는 포인트 활성 효과 제외

- 진화 카르마 수치를 파싱하지 못해 예시값 +6.0%를 사용했습니다.
