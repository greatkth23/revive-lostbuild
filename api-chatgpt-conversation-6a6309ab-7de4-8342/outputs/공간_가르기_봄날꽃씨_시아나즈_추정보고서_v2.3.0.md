# 공간 가르기 피해 추정 요약 — 봄날꽃씨·시아나즈

- 계산기: `2.3.0`
- 파서: `lostark-api-v2.3.0`
- 규칙: `current-v2.3.0`
- DB 릴리스: `weather-artist-v0.2`
- 데이터: 두 캐릭터의 보존된 Lost Ark Open API 스냅샷
- 계산 단위: 공간 가르기 1회 사용, 1타+2타

## 결론

| 캐릭터 | 1타 비치명 | 2타 비치명 | 합계 비치명 | 합계 치명 | 합계 기대 피해 | 치명타율 |
|---|---:|---:|---:|---:|---:|---:|
| 봄날꽃씨 | 74,389,517 | 173,581,810 | 247,971,327 | 731,796,318 | 711,282,139 | 95.7600% |
| 시아나즈 | 100,217,004 | 233,848,111 | 334,065,115 | 972,198,970 | 960,584,934 | 98.1800% |

시아나즈의 1회 기대 피해는 봄날꽃씨보다 249,302,795 높으며,
약 35.05% 큰 추정값이다.

## 타격 모델

| 타격 | 모션 계수 | 모션 상수 | 본체 공식 |
|---|---:|---:|---|
| 1타 | 40.07 | 6,117 | `40.07 × 사용 공격력 + 6,117` |
| 2타 | 93.50 | 14,283 | `93.50 × 사용 공격력 + 14,283` |

두 캐릭터 모두 재구성 공격력과 API 프로필 공격력이 달랐다. 계산 과정에는
재구성 공격력 산식을 보존하되, 실제 타격 본체와 이후 피해 계산에는 감사 규칙에
따라 프로필 공격력을 사용했다.

| 캐릭터 | 재구성 공격력 | 프로필 공격력 | 피해 계산 사용값 |
|---|---:|---:|---:|
| 봄날꽃씨 | 235,138.7047847067 | 217,160 | 217,160 |
| 시아나즈 | 255,711.5573573904 | 241,195 | 241,195 |

## 적용 범위

- 두 캐릭터의 API 툴팁에서 `공간 가르기 Lv.3`의 피해 +200%를 읽어
  1타와 2타 각각에 `×3.0`으로 적용했다.
- 두 캐릭터 모두 공간 가르기 전용 일반 보석이 없어 일반 보석 스킬 피해는
  0%이다. 다른 스킬의 보석 효과는 파싱하되 이 계산에서는 제외했다.
- `바람의 길`은 우산 스킬 전용, `풀려난 힘`은 초각성 스킬 전용,
  `단련된 가르기`는 우레바람 전용으로 판정해 제외했다.
- ArkGrid의 공격력·추가 피해·보스 피해를 각각 해당 계산 그룹에 적용했다.
- 봄날꽃씨의 `타격의 대가` 17%는 공간 가르기를 비방향성·비각성 공격으로
  잠정 분류해 적용했다. 공식 API 스냅샷에는 공간 가르기의 방향성 분류 필드가
  없으므로 이 항목은 `PROVISIONAL`이다.
- 시아나즈는 타격의 대가를 장착하지 않아 위 잠정 분류가 결과값에 영향을
  주지 않는다.

## 검증

- 단위·회귀 테스트 16개 통과
- 두 실제 스냅샷 계산의 구조 검증 통과
- 타격별 원시 피해 합계와 1회 사용 총합 일치
- 최종 비치명·치명·기대 피해의 `floor` 검증 통과
- DB `skill_hits`에 1타와 2타 계수·상수 저장 검증 통과

세부 파싱 출처, 모든 배율, 공격력 재구성 과정 및 제외 목록은 캐릭터별
`current-v2.3.0` 계산 보고서와 파싱 JSON에 기록했다.
