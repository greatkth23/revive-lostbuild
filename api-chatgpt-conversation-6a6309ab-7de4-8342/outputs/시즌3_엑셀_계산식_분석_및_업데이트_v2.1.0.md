# 시즌3 엑셀 계산식 분석 및 계산기 v2.1.0 업데이트

## 결론

`시즌3 전용 데미지 계산기.xlsx`는 최종 피해를 다음 다섯 요소의 곱으로 계산한다.

```text
최종 피해
= 공격력
× 각인 피해 증가
× 스킬 기대 피해
× 추가 피해
× 기타 피해 증가
```

근거 수식은 `BI4 = BI8*BI9*BI10*BI11*BI12`이다.  
【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!BH4:BI12】

기존 API 계산기는 이 구조와 대체로 같은 방향이었지만, 공격력 내부의 평면 증가값, 현재 API 각인 설명, 버전별 버림 규칙이 충분히 분리되어 있지 않았다. v2.1.0에서는 이를 보강했다.

## 1. 엑셀 계산 구조

### 1.1 힘민지

```excel
=ROUNDDOWN(SUM(M8:M15)*(1+P8),0)
```

- 평면 주스탯을 먼저 합산한다.
- 아바타 주스탯 비율을 합산값에 곱한다.
- 엑셀 원본은 이 단계에서 버린다.

【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!L4:P15】

### 1.2 무기 공격력

```excel
=ROUNDDOWN(SUM(M18:M22)*(1+P18),0)
```

- 무기 기본 공격력과 장신구·팔찌 등의 평면 무기 공격력을 먼저 합산한다.
- 장신구 무기 공격력 `%`를 그 합계에 적용한다.
- 엑셀 원본은 이 단계에서 버린다.

【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!L17:P22】

### 1.3 최종 공격력

```excel
=ROUNDDOWN(
  (
    (M4*M5/6)^0.5
    *(1+SUM(P25:P26))
    +SUM(M25:M27)
  )
  *(1+SUM(P29:P34)),
0)
```

계산 순서는 다음과 같다.

```text
1. sqrt(힘민지 × 무기 공격력 ÷ 6)
2. 기본 공격력 % 적용
3. 공격력 평면 증가 합산
4. 공격력 % 적용
5. 엑셀 원본은 최종 공격력에서 버림
```

【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!L24:P34】

### 1.4 각인

엑셀은 적용 대상 각인을 서로 독립 배율로 곱한다.

```excel
=(1+T8+V8)
 *(1+T9+V9)
 ...
 *(1+T22+V22)
```

각인서 수치와 어빌리티 스톤 수치는 같은 각인 내부에서 먼저 더하고, 다른 각인과는 곱한다. 스킬 조건이 필요한 붉은 글씨 각인은 스킬 계산 블록에서 처리한다.

【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!R4:W34】

### 1.5 치명·신속 환산

엑셀에 포함된 환산 계수는 다음과 같다.

```text
치명타율 = 치명 × 0.0003578586
공격속도 증가 = 신속 × 0.000171759
이동속도 증가 = 신속 × 0.000171759
```

API `Stats[].Tooltip`에서 최종 환산율을 읽지 못했을 때 사용할 수 있는 보조 계수로 반영했다.

【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!Z8:AA8】  
【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!AC8:AE17】

### 1.6 스킬 기대 피해

각 스킬은 다음 순서로 정규화된다.

```text
기본 피해 × 횟수
→ 전체 스킬 피해 합에서 차지하는 비중
→ 트라이포드·조건부 각인 적용
→ 치명타 확률과 치명타 피해의 기대값
→ 진화형 피해
→ 헤드/백 성공률과 방향성 피해
→ 모든 스킬의 기여도 합산
```

최종 스킬 기대 피해는 `BB4 = SUM(BB8:BB27)`이다. 우레바람 단일 시전 계산에서는 전체 로테이션 비중을 사용하지 않지만, 향후 DPS·스킬 비중 계산 모듈을 추가할 때 적용할 수 있도록 별도 구조로 분류했다.

【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!AN7:BB39】

### 1.7 추가 피해와 기타 피해

추가 피해는 한 그룹 안에서 더한다.

```excel
=SUM(BF8:BF12)+1
```

기타 피해 증가는 소제목별로 곱한다.

```excel
=(1+BF15)*(1+BF16)*...*(1+BF23)
```

【시즌3 전용 데미지 계산기.xlsx:데미지 계산기!BD4:BF23】

## 2. 기존 규칙과 충돌한 항목

| 항목 | 엑셀 원본 | 이전에 사용자가 확정한 최신 규칙 | 처리 |
|---|---|---|---|
| 중간 버림 | 힘민지·무기 공격력·공격력에서 버림 | 최종 피해에서만 버림 | 버전 분리 |
| 음속 돌파 Lv.2 초과분 계수 | 20% | 30% | 버전 분리 |
| 음속 돌파 Lv.1 초과분 계수 | 10% | 15% | 버전 분리 |
| 펫 주스탯·추가 피해 | 엑셀 입력 블록에 없음 | 기본 프리셋으로 적용 | 최신 규칙에서 유지 |
| 원정대/물약 주스탯 | 엑셀 표본값 702 | 예시 고정값 680과 내실 976 분리 | 버전 분리 |
| 만찬 속도 | 엑셀 표본값 3.5% | 사용자 기본값 5% | 버전 분리 |

최신 기본 버전은 명시적인 사용자 지시를 엑셀보다 우선한다.

```text
사용자 명시 규칙
> 현재 API 설명
> 엑셀 수식
> 예시 fallback DB
```

## 3. 버전

### `example-v1.0.0`

- 기존 대화 예시의 동작 보존
- 중간 버림 없음
- 예시 각인 수치 사용
- 평면 무기 공격력·평면 공격력 미반영
- 음속 돌파 초과분 계수 Lv.1 15%, Lv.2 30%

### `season3-xlsx-v2.0.0`

- 엑셀 공격력 파이프라인 적용
- 힘민지·무기 공격력·공격력 단계 버림
- 평면 무기 공격력·평면 공격력 반영
- 현재 API 각인 설명 우선
- 음속 돌파 초과분 계수 Lv.1 10%, Lv.2 20%
- 엑셀 표본값과 같은 702 원정대/물약, 만찬 3.5% 사용

### `current-v2.1.0` — 기본

- 엑셀의 강화된 공격력 단계와 효과 그룹 구조 사용
- 현재 API 각인 설명에서 실제 수치 파싱
- 평면 무기 공격력·평면 공격력 반영
- 사용자 지시에 따라 중간 버림 없음
- 아바타와 펫 비율 합연산
- 음속 돌파 초과분 계수 Lv.1 15%, Lv.2 30%
- 펫·만찬·전투 축복 등 기존 사용자 프리셋 유지

버전 정의와 수식 근거는 `데미지_계산규칙_versions.json`에 기계 판독 가능한 형태로 저장했다.

## 4. 구현된 강화 사항

1. `--rules-version` 옵션으로 규칙 버전을 선택한다.
2. 결과 파일명에 규칙 버전을 포함해 덮어쓰기를 방지한다.
3. 장신구·팔찌 툴팁에서 평면 `무기 공격력 +N`, `공격력 +N`을 별도 파싱한다.
4. 공격력을 엑셀과 같은 다섯 단계로 분해한다.
5. 현재 각인 설명에서 다음 값을 직접 파싱한다.
   - 원한 실제 피해 증가
   - 저주받은 인형 실제 피해 증가
   - 질량 증가 피해 및 공격속도 감소
   - 아드레날린 스택당 공격력·최대 스택·치명타율
   - 돌격대장 이동속도 계수
6. 이전에 누락됐던 저주받은 인형을 적용한다.
7. API 설명을 읽지 못한 경우에만 예시 DB를 사용한다.
8. 치명·신속 툴팁 환산 실패 시 엑셀 계수를 fallback으로 사용한다.
9. 각 중간 단계의 원시값, 버림 여부, 적용 후 값을 JSON과 보고서에 모두 기록한다.
10. 초월, 비활성 아크그리드 젬, 서포터 젬 효과 제외 규칙을 유지한다.

## 5. 검증

- 오프라인 단위 테스트 10개 통과
- 세 버전의 중간 버림 정책 분리 검증
- 음속 돌파 버전별 계수 분리 검증
- 현재 API 각인 설명 우선 적용 검증
- 저주받은 인형 적용 검증
- 평면 무기 공격력·공격력 파싱 검증
- 아크그리드 적용 전후 연결 검증
- 최종 비치명타·치명타·기대 피해의 버림 검증

과거 캐릭터 스펙과의 피해 회귀검증은 수행하지 않았다.

### 동일 API 스냅샷의 버전별 출력 예시

시아나즈의 기존 API 스냅샷을 각 규칙으로 다시 계산한 결과다. 서로 다른 규칙의 결과이므로 우열 비교나 과거 피해 회귀검증으로 사용하지 않는다.

| 규칙 버전 | 비치명타 | 치명타 | 기대 피해 |
|---|---:|---:|---:|
| `example-v1.0.0` | 428,448,881 | 1,246,875,363 | 1,231,980,001 |
| `season3-xlsx-v2.0.0` | 521,531,810 | 1,517,766,048 | 1,499,634,585 |
| `current-v2.1.0` | 534,440,793 | 1,555,333,873 | 1,536,753,619 |

주요 차이는 현재 각인 수치, 저주받은 인형, 평면 무기 공격력·공격력, 중간 버림, 펫·만찬, 음속 돌파 계수에서 발생한다.

## 6. 남은 한계

- 엑셀의 `BB4`는 여러 스킬의 피해 비중과 방향 성공률을 합산하는 로테이션 기대값이다. 현재 API 계산기는 우레바람 단일 시전의 치명·비치명·기대 피해를 계산하므로 이 값을 그대로 곱하지 않는다.
- 카르마 API 설명은 현재 `6랭크 30레벨`처럼 랭크·레벨만 반환해, 진화 `+6%`, 깨달음 무기 공격력 `+2.7%`는 여전히 예시 DB fallback이다.
- API 설명에서 수치를 읽더라도 적용 범위가 등록되지 않은 새로운 각인은 자동 적용하지 않고 경고한다.
- 스킬 모션 계수와 상수, 적 방어력·받는 피해는 기존 외부 DB·시나리오 입력을 계속 사용한다.
