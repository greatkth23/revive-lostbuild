## 3. 계산 과정

모든 중간값은 소수로 유지했습니다. 아래 세 최종 표시 피해에서만 `floor`를 적용했습니다.

### 3.1 주스탯

`기초 지능 = 750477 + 477 + 680 + 976 = 752610`

`아바타+펫 = 8.0000% + 1.0000% = 9.0000%`

`최종 지능 원시값 = 752610 × (1 + 0.09) = 820344.90`

`규칙 적용 최종 지능 = 820344.90`

### 3.2 무기 공격력

`무기 공격력 증가 = 6.0000% + 3.0000% + 아크그리드 코어 0.0000% = 9.0000%`

`무기 공격력 소계 = 기본 241367 + 장비 평면 증가 1440 + 아크그리드 코어 평면 증가 0 = 242807`

`최종 무기 공격력 원시값 = 242807 × (1 + 0.090) = 264659.630`

`규칙 적용 최종 무기 공격력 = 264659.630`

### 3.3 기본 공격력과 최종 공격력

`sqrt(820344.90 × 264659.630 ÷ 6) = 190224.5067047474301321909063653257612399`

`기본 공격력 증가 = 보석 13.2000% + 스톤 1.5000% = 14.7000%`

`루트 공격력 × 기본 공격력% = 190224.5067047474301321909063653257612399 × (1 + 0.147) = 218187.5091903453023616229696010286481422`
