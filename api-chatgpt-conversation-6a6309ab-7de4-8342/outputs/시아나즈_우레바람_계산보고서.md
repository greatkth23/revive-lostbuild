- 현재 원정대 레벨은 400이지만 원정대 주스탯은 예시값 +680을 사용했습니다.

## 6. 검증 결과

- 과거 스펙의 최종 피해와 회귀 비교하지 않았습니다.
- 원본 API 경로와 각 파싱값을 출처 표로 연결했습니다.

- 아크그리드 적용 전후 계산을 별도로 수행했습니다.
