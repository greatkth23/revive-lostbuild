## 3. 계산 과정

모든 중간값은 소수로 유지했습니다. 아래 세 최종 표시 피해에서만 `floor`를 적용했습니다.

### 3.1 주스탯

`기초 지능 = 701492 + 477 + 680 + 976 = 703625`

`아바타+펫 = 8.0000% + 1.0000% = 9.0000%`

`최종 지능 원시값 = 703625 × (1 + 0.09) = 766951.25`

`규칙 적용 최종 지능 = 766951.25`

### 3.2 무기 공격력

`무기 공격력 증가 = 6.0000% + 2.7000% + 아크그리드 코어 3.0000% = 11.7000%`

`무기 공격력 소계 = 기본 241367 + 장비 평면 증가 0 + 아크그리드 코어 평면 증가 5200 = 246567`

`최종 무기 공격력 원시값 = 246567 × (1 + 0.1170) = 275415.3390`

`규칙 적용 최종 무기 공격력 = 275415.3390`

### 3.3 기본 공격력과 최종 공격력

`sqrt(766951.25 × 275415.3390 ÷ 6) = 187630.0164842252125734667727901833052462`

`기본 공격력 증가 = 보석 10.2000% + 스톤 1.5000% = 11.7000%`

`루트 공격력 × 기본 공격력% = 187630.0164842252125734667727901833052462 × (1 + 0.117) = 209582.7284128795624445623852066347519600`

`기본 공격력 단계 = 209582.7284128795624445623852066347519600 + 장비 공격력 평면 증가 0 + 아크그리드 코어 평면 증가 0 = 209582.7284128795624445623852066347519600`

`공격력 증가 = 장신구 1.9000% + 아드레날린 10.3800% + 아크그리드 누적 효과(Effects[]) 1.3500% + 아크그리드 코어 0.0000% = 13.6300%`

`아크그리드 활성 젬 공격력 상세 = 슬롯 0/젬 2 0.1800% + 슬롯 0/젬 3 0.0300% + 슬롯 1/젬 0 0.0300% + 슬롯 1/젬 1 0.1800% + 슬롯 2/젬 1 0.0700% + 슬롯 2/젬 3 0.1100% + 슬롯 3/젬 0 0.1100% + 슬롯 3/젬 1 0.1400% + 슬롯 3/젬 2 0.1100% + 슬롯 4/젬 1 0.1800% + 슬롯 5/젬 0 0.1800% = 1.3200% (Effects[] 원천 검산값, 중복 합산하지 않음)`
