- 계산기: `2.4.0`
- 파서: `lostark-api-v2.4.0`

- DB 릴리스: `weather-artist-v0.3`
- 계산 단위: 공간 가르기 1회 사용, 1타+2타

## 적용된 ArkGrid 코어 효과

### 봄날꽃씨

- 혼돈의 해 코어 `현란한 공격` 19P
  - 치명타 시 피해: 10P 0.55% + 17P 1.10% = 1.65%
  - 적에게 주는 피해: 14P 0.50% + 17P 1.50%
    + 18P 0.16% + 19P 0.16% = 2.32%
- 혼돈의 달 코어 `불타는 일격` 20P
  - 보스 피해: 14P 0.50% + 17P 2.00%
    + 18P·19P·20P 각 0.16% = 2.98%
  - 화상은 피해 계수가 제공되지 않아 별도 피해를 합산하지 않았다.
- 혼돈의 별 코어 `무기` 17P
  - 무기 공격력 +5,200, 무기 공격력 +3.00%
  - 재구성 공격력에는 포함하지만 실제 스킬 피해는 프로필 공격력을 사용한다.

### 시아나즈

- 혼돈의 해 코어 `재빠른 공격` 20P
  - 공격속도: 10P 1.00% + 17P 3.00% = 4.00%
  - 치명타 피해: 14P 1.40% + 17P 5.60%
    + 18P·19P·20P 각 0.45% = 8.35%
- 혼돈의 달 코어 `흡수의 일격` 20P
  - 적에게 주는 피해: 14P 0.50% + 17P 2.00%
    + 18P·19P·20P 각 0.16% = 2.98%
  - 생명력 회복 효과는 개인 1회 피해에서 제외했다.
- 혼돈의 별 코어 `공격` 19P
  - 공격력 +3,600, 공격력 +2.52%
  - 재구성 공격력에는 포함하지만 실제 스킬 피해는 프로필 공격력을 사용한다.

## 공통 적용 범위

- 공간 가르기 1타는 `40.07 × 공격력 + 6,117`, 2타는
  `93.50 × 공격력 + 14,283`으로 계산했다.
- `공간 가르기 Lv.3` 피해 +200%를 양쪽 타격에 적용했다.
- 공간 가르기는 우산 스킬로 분류하지 않아 비연참·우산의 춤·휘몰아치기
  등 질서 코어의 우산 스킬 및 지정 스킬 피해는 적용하지 않았다.
- 전용 일반 보석은 두 캐릭터 모두 0%다.
- 재구성 공격력과 프로필 공격력이 불일치하여 피해 계산에는 프로필 공격력을
  사용하고 재구성 과정만 검산용으로 보존했다.
- 봄날꽃씨의 타격의 대가는 공간 가르기를 비방향성·비각성 공격으로
  잠정 분류해 적용했다. 시아나즈는 해당 각인을 장착하지 않았다.
