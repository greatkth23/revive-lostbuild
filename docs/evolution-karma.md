# 진화 카르마 계산 규칙

근거: 사용자가 제공한 랭크-레벨 표, 2026-09-04.

| 랭크 | 가능한 레벨 | 진화형 피해 | 낙인력 | 최대 생명력 증가 |
| --- | --- | --- | --- | --- |
| 1 | 1–5 | 1% | 1% | 400–2,000 |
| 2 | 5–9 | 2% | 2% | 2,000–3,600 |
| 3 | 9–13 | 3% | 3% | 3,600–5,200 |
| 4 | 13–17 | 4% | 4% | 5,200–6,800 |
| 5 | 17–21 | 5% | 5% | 6,800–8,400 |
| 6 | 21–30 | 6% | 6% | 8,400–12,000 |

- 진화형 피해 증가율 = 랭크 × 0.01. 낙인력 증가율도 동일하다.
- 최대 생명력 증가량 = 레벨 × 400. 랭크 승급 자체로는 생명력이 증가하지 않는다.
- 5·9·13·17·21레벨은 승급 전후 랭크에 모두 존재하므로 레벨이나 아크 패시브 포인트(`Value`)에서 랭크를 추정하지 않는다.

## 개인 피해 계산 적용

`진화형 피해 배율 = 1 + 기존 진화형 피해 증가율 합계 + 진화 카르마 랭크 × 0.01`

예를 들어 기존 진화형 피해가 50%이고 카르마가 3랭크라면 배율은 `1.53`이다. 별도 `1.03` 배율을 곱하지 않는다. 낙인력과 최대 생명력은 이 계산기의 개인 스킬 피해 배율에 추가하지 않는다.

웹 TypeScript 파서와 Python 계산기 모두 API 진화 항목의 `Description` 또는 `Tooltip`에서 명시된 랭크를 사용한다. 0랭크는 미적용 상태로 0%를 사용한다. 랭크가 없고 진화형 피해 %가 명시된 기존 툴팁은 해당 수치를 사용한다. 유효한 랭크가 있으면 랭크 기준값을 우선하고, 툴팁 수치와 충돌하면 경고한다. 알 수 없는 랭크나 불충분한 설명에는 6% 예시값을 넣지 않고 미적용 경고를 남긴다.

기존 합산 계산식과 계산 내역의 `진화 카르마` 항목을 사용하며, 웹 파서 버전은 `lostark-api-ts-v3`로 올려 이전 파서의 캐시를 재사용하지 않는다. Python 파서 버전은 `lostark-api-v2.7.2`이다.

회귀 검증: 제공된 표의 35개 조합, 승급 경계, 미확인 랭크, 툴팁 숫자와의 충돌, 6개 스킬의 일반/치명타/기대 피해 합산 배율.
