# 질풍노도 기상술사 데미지 시뮬레이터 설계

## 목표

기존 Python `current-v2.7.2` 계산 규칙을 TypeScript로 이식하고, Lost Ark Open API에서 불러온 질풍노도 기상술사의 세팅을 사용자가 인게임 제약 안에서 조정한 뒤 원본·수정 세팅의 스킬 1회 피해를 비교하는 비상업 공개 웹 서비스를 제공한다.

첫 릴리스는 우레바람, 공간 가르기, 바람송곳, 칼바람, 몰아치기, 회오리 걸음만 지원한다. 검증된 쿨다운 중첩 규칙이 없으므로 DPS와 회전 시뮬레이션은 제외한다.

## 구조

- npm workspace 모노레포: React 웹, Cloudflare Worker, 공용 계약, 계산 엔진, 카탈로그.
- Worker 한 개가 정적 웹 자산과 `/api/v1/*`를 제공한다.
- Lost Ark JWT는 Worker Secret에만 저장한다.
- 정규화된 캐릭터 스냅샷은 KV에서 5분간 캐시한다.
- 전역 Durable Object가 동일 캐릭터 요청을 합치고 공식 API 호출을 분당 90회 이하로 제한한다.
- 브라우저는 원본 스냅샷이 아닌 검증 가능한 `BuildPatch[]`만 로컬 저장한다.

## 계산 규칙

- Python과 동일한 정밀도 40의 십진 연산 및 반올림 지점을 사용한다.
- 프로필 공격력이 아닌 `current-v2.7.2`의 계산된 공격력을 공식값으로 사용한다.
- 장비·완갑·액세서리·팔찌·아바타·펫, 각인·어빌리티 스톤·카드, 보석, 아크패시브, 아크그리드, 트라이포드를 현재 Python과 같은 카테고리와 순서로 적용한다.
- 활성 아크그리드 젬과 `ArkGrid.Effects[]`가 같은 효과를 표현하면 한 번만 적용한다.
- 아크그리드의 등급별 `/` 값과 18–20P 포인트별 반복 곱연산을 유지한다.
- 공간 가르기는 우산 스킬이고 사용자 확정 보정인 모션계수 29.2% 증가를 적용한다.
- `NON_DIRECTIONAL`은 방향 보너스가 없고, 백 어택 성공은 피해 5% 및 치명타율 10%p, 헤드 어택 성공은 피해 20%를 적용한다.
- API와 엔진 경계의 모든 계산 수치는 소수 문자열이다. UI에서만 소수점 둘째 자리로 표시한다.
- 피해 관련 미해석 툴팁을 0으로 묵살하지 않고 필드 경로가 포함된 `검증 불완전` 경고로 반환한다.

## 공용 계약

- `BuildSnapshot`: API에서 파싱한 원본 세팅, 경고, 계산기·파서·카탈로그 버전.
- `BuildPatch`: 카탈로그 ID와 슬롯을 대상으로 하는 판별 유니온 변경 명령.
- `Scenario`: 최대 유리 보스 조건과 스킬별 방향성 성공 여부.
- `SkillDamageResult`: 비치명·치명·기대 피해, 치명타율·배율, 타격별 결과와 계산 근거.

API는 `POST /api/v1/characters/load`, `GET /api/v1/catalog/weather-artist`, `POST /api/v1/simulations`로 고정한다.

## 화면

- `세팅 조정`과 `스킬 피해 결과` 두 탭.
- 장비·완갑, 액세서리·팔찌, 보석, 각인·어빌리티 스톤, 아크패시브, 아크그리드, 카드·아바타·펫, 스킬·트라이포드 카드.
- 인게임에서 가능한 선택만 허용하고 서버도 같은 제약을 검증한다.
- 섹션·전체 복원, API 새로고침, 250ms 디바운스 재계산, 버전별 localStorage 패치 보존.
- 결과는 원본·수정 세팅을 나란히 비교하며 다단 히트와 계산 근거를 펼쳐 볼 수 있다.
- 데스크톱 3열 정보 구조, 태블릿 2열, 모바일 단일 열 접이식 구조.

## 운영·범위 제한

- 비상업 공개, 로그인·서버 저장·공유 링크 없음.
- API 아이콘 URL만 표시하며 이미지를 저장소에 복제하지 않는다.
- 제공되지 않은 장비 성장표 구간은 강화·품질 입력을 잠근다. 출처·버전·완전성 검사를 통과한 데이터만 잠금을 해제한다.
- 익명 브라우저 ID별 캐시 미스 분당 3회, 강제 새로고침 60초당 1회. Turnstile은 기본 비활성 기능 플래그다.
- 로그에는 요청 ID, 경로, 상태, 지연시간, 캐시 여부와 버전만 남기고 캐릭터명·툴팁·세팅은 남기지 않는다.

## 완료 조건

- 저장된 봄날꽃씨 API 픽스처에서 Python과 TypeScript의 주요 중간값 및 6개 스킬 결과가 일치한다.
- 편집 제약, 원본·수정 비교, 로컬 복원, 오류 상태, 반응형 흐름을 자동 테스트한다.
- 빌드 산출물·응답·로그에 JWT가 없고 타입 검사, 단위·통합·E2E 테스트와 실제 API 스모크 절차가 준비된다.
